# Python Data Types

## What is a Data Type?

A **data type** defines the kind of value a variable can hold and the operations that can be performed on it.  
Think of it like knowing whether something is a number, text, or a true/false value, so you can handle it correctly.

---

## Categories of Data Types in Python

Python data types can be classified into two main categories:

1. **Built-in Data Types** – Provided by default in Python.  
2. **User-Defined Data Types** – Created by the programmer (e.g., Classes).

---

## Built-in Data Types

### 1. Numeric Types
- **int** – Integer numbers (e.g., 5, 10, 1000)  
- **float** – Decimal numbers (e.g., 3.14, 0.5)  
- **complex** – Numbers with real and imaginary parts (e.g., 3 + 4j)

### 2. Text Type
- **str** – Represents text or string values (e.g., "Hello", "Python")  

### 3. Boolean Type
- **bool** – Represents logical values: `True` or `False`

### 4. Sequence Types
- **list** – Ordered, mutable collection of items  
- **tuple** – Ordered, immutable collection of items  
- **range** – Represents a sequence of numbers  

### 5. Mapping Type
- **dict** – Unordered collection of key-value pairs. Keys are unique and immutable, values can be any type.

### 6. Set Types
- **set** – Unordered collection of unique items  
- **frozenset** – Immutable version of a set  

### 7. Binary Types
- **bytes** – Immutable sequence of bytes  
- **bytearray** – Mutable sequence of bytes  
- **memoryview** – Memory view object that references existing byte data  

### 8. None Type
- **None** – Represents nothing, empty, or null. Used as a placeholder or to indicate no value.

---

## Key Characteristics of Python Data Types

- **Dynamic Typing:** Python automatically assigns a data type based on the value.  
- **Strong Typing:** Python enforces type rules; you cannot perform incompatible operations without explicit conversion.  

---

## Type Conversion

Python allows explicit conversion between data types using built-in functions. This helps when working with different types in operations or assignments.
